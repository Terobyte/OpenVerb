## mmproj Status

**Verdict:** PASS

**Working invocation:**
```
validation/deps/llama.cpp/build/bin/llama-mtmd-cli \
  -m validation/models/gemma-4-E2B-it-Q4_K_M.gguf \
  --mmproj validation/models/mmproj-BF16.gguf \
  --audio validation/audio/short-en-clean.wav \
  -p "Transcribe this audio." \
  -sys "Output only the verbatim transcription. No thinking, no explanations." \
  -n 512 --no-warmup --jinja
```

**Notes:**
- `--jinja` flag is **required** — without it Gemma 4 throws `std::runtime_error: this custom template is not supported`. This is because Gemma 4 uses a Jinja2 chat template, not a legacy C-format template.
- Both `llama-mtmd-cli` (primary) and `llama-cli` (fallback) are built and support `--audio`. `llama-mtmd-cli` preferred.
- Gemma 4 outputs thinking tokens wrapped in `<|channel>thought...<channel|>RESPONSE`. Output parsing must split on `<channel|>` and take the right side.
- `-sys` system prompt is effective for suppressing thinking verbosity.

## Recommended Quantization

**Default: Q4_K_M**

**Rationale:** Q4_K_M achieves 13.9% average WER (under 15% threshold), zero repetition, and fits in 16 GB unified memory with room for KV cache and system overhead. Q8_0 and BF16 offer no measured benefit for the tested use case and would increase model load time and RAM pressure.

## Overall Path A Verdict

**CONDITIONS**

- [x] **GO** on accuracy — WER 13.9% is within 15% threshold
- [x] **GO** on repetition — 0% flagged
- [ ] **CONDITIONS** on latency — production eval ~6s per utterance (target was <2s)

**Conditions:**

1. **Latency condition:** The 2s end-to-end target requires a **persistent model process**. Cold-start CLI (this benchmark) = 4.2s load + 6s eval = ~10s. With model loaded in memory (MVP1 daemon/engine), only eval_ms applies ≈ 5-7s. This is above the 2s aspirational target but acceptable for dictation UX where users speak then wait briefly.

2. **Long audio limitation:** WER degrades significantly above ~30 seconds (two-min: 33.7%). Not a concern for real-time dictation (target: short-to-medium utterances, not batch transcription).

3. **Multilingual validation (informal):** Russian ≈ 0% WER, French ≈ 1% WER, Chinese degraded (traditional/simplified mixing, semantic drift). Only English is the official supported language for MVP1.
