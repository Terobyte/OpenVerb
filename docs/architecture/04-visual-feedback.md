# Визуальный отклик: анимация, микроинтеракции и плавающий UI

## Психологическая роль визуального фидбека

**Проблема**: обработка аудио + генерация текста требует времени:
- STT: 200–500мс
- LLM: 500–2000мс
- **Итого**: 1–3 секунды задержка

**Без фидбека**: пользователь испытывает тревогу, теряет концентрацию.

**С фидбеком**: система подтверждает, что она "слышит", сохраняя пользователя в состоянии "потока".

## Потоковая архитектура распознавания (Streaming STT)

### Два параллельных потока данных

#### Interim Results (Промежуточные результаты)

```
Audio chunks: [chunk1] [chunk2] [chunk3] → STT Engine
                                              ↓
Return: "Hel" (50ms) → "Hello t" (100ms) → "Hello the" (150ms)
```

**Характеристики:**
- Возвращаются мгновенно (< 100мс задержка)
- Нестабильны, часто изменяются
- Могут быть переосмыслены в контексте

**Пример ретроспективного исправления:**
```
Пользователь говорит: "write of way"

Interim 1: "write of way"
Interim 2: "right of way"  ← переосмыслено на основе контекста
Final: "right of way"
```

#### Final Results (Окончательные результаты)

```
"right of way" → [LLM Processing] → "Right-of-way"
```

**Характеристики:**
- Стабильны, не изменяются
- Прошли проверку LLM
- Готовы к инъекции в документ

## Эффект "призрачного текста" (Ghosting)

### Визуальная реализация

```
┌──────────────────────────────┐
│ Hello (stable text - черный) │
│ the (interim - серый, 50%)   │ ← полупрозрачный
└──────────────────────────────┘
```

### CSS-анимация

```css
.interim-text {
  opacity: 0.5;
  color: #888;
  font-style: italic;
  transition: all 200ms ease-in-out;
  filter: blur(0.5px);  /* легкое размытие для "нестабильности" */
}

.final-text {
  opacity: 1;
  color: #000;
  font-style: normal;
  filter: blur(0px);
}
```

### Психологический эффект

| Визуальный элемент | Сигнал пользователю |
|------------------|-------------------|
| **Полупрозрачность** | "Это может измениться" |
| **Светло-серый цвет** | "Это не финальный результат" |
| **Размытие** | "Система еще обрабатывает" |
| **Плавный переход в черный** | "Текст зафиксирован" |

**Результат**: пользователь не пытается редактировать промежуточный текст.

## Потоковый эффект печати (Typing Effect)

### Проблема: рывки при поступлении токенов

```
Поступление токенов:    [====token====] pause [==token==] [token] [token]
Без оптимизации:        "Hello" (pause 500ms) "world!" (pause 100ms)
```

**Выглядит неестественно.**

### Решение: имитация человеческого темпа

```javascript
async function streamTextWithNaturalSpeed(tokens) {
  const baseSpeed = 50; // мс между символами
  let buffer = '';

  for (const token of tokens) {
    buffer += token;

    // Вычислить базовый интервал
    let interval = baseSpeed * token.length;

    // Добавить легкую случайность (±20%)
    interval *= (0.8 + Math.random() * 0.4);

    displayText(buffer);
    await sleep(interval);
  }
}
```

**Результат:** печать выглядит органичной, несмотря на неравномерность поступления.

### Примеры интервалов

| Символ | Интервал |
|--------|----------|
| Пробел | 30мс |
| Буква | 50мс |
| Пунктуация | 100мс (пауза перед) |
| Перевод строки | 200мс |

## Плавающий интерфейс (Cursor-Following UI)

### Архитектура

```
┌─────────────────────────────────────┐
│ User's Text Field / Code Editor     │
│                                     │
│ Some text here where cursor | is   │
│          ↑                          │
│   [◉ Recording...] ← plFloating UI  │
│     (Glassmorphism)                 │
└─────────────────────────────────────┘
```

### Вычисление позиции

```swift
// 1. Получить диапазон выделения (или позицию курсора)
let selectedRange = element.selectedTextRange  // (0, 0) = позиция

// 2. Получить координаты этой позиции
let bounds = element.boundingBox(forRange: selectedRange)
// bounds = CGRect(x: 150, y: 200, width: 2, height: 20)

// 3. Позиционировать плавающее окно
floatingUI.position = CGPoint(
  x: bounds.midX - floatingUI.width / 2,  // Центрировать над курсором
  y: bounds.minY - floatingUI.height - 10  // Выше курсора с отступом
)
```

### Glassmorphism эффект

```css
.floating-ui {
  background: rgba(255, 255, 255, 0.7);
  backdrop-filter: blur(10px);
  border: 1px solid rgba(255, 255, 255, 0.3);
  border-radius: 12px;
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.1);

  animation: pulse 1.2s ease-in-out infinite;
}

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.05); }
}
```

**Преимущества:**
- Не закрывает текст полностью
- Видно, что это временный элемент
- Красиво выглядит в современных ОС

## Обработка динамических позиций

### Проблема: курсор движется во время диктовки

```
Пользователь диктует: "Hello world"
                             ↓
           Движение мышки в процессе диктовки
                             ↓
Плавающий UI должен следовать за курсором
```

### Решение: периодическое обновление

```javascript
let cursorFollowInterval = setInterval(() => {
  if (isRecording) {
    const newBounds = getElementBounds();

    // Плавная анимация к новой позиции
    floatingUI.animate({
      position: newBounds,
      duration: 200  // мс
    });
  }
}, 100);  // Обновлять каждые 100мс
```

**Баланс:**
- Достаточно частое обновление (плавно следует)
- Не слишком частое (не перегружает CPU)

## Специальные визуальные состояния

### Loading State (Обработка)

```
[◉●○○○ Processing...] ← spinning dots
```

### Error State (Ошибка)

```
[⚠ Mic not accessible - Retry?]
├─ Красный фон
├─ Значок ошибки
└─ Кнопка повтора
```

### Success State (Успех)

```
[✓ Inserted successfully]
├─ Зеленый фон
├─ Исчезает через 2 секунды
└─ Плавное размытие (dissolve effect)
```

## Микроинтеракции и звуковая обратная связь

### Звуки для каждого события

| Событие | Звук | Длина | Назначение |
|--------|------|-------|-----------|
| **Начало записи** | Высокий бип | 100мс | Подтверждение активации |
| **Промежуточный результат** | Мягкий звон | 50мс | Пользователь услышан |
| **Окончательный результат** | Приятный звон | 150мс | Успех, готово к инъекции |
| **Ошибка** | Низкий звон | 200мс | Проблема требует внимания |

### Haptic Feedback (для мобильных)

```
Начало: .light
Промежуточный: .selection (вибрация)
Окончательный: .medium
Ошибка: .heavy
```

## Анимация текста при инъекции

### Вариант 1: Плавный появление (Fade-in)

```css
@keyframes fadeIn {
  0% { opacity: 0; }
  100% { opacity: 1; }
}

.injected-text {
  animation: fadeIn 300ms ease-in;
}
```

### Вариант 2: Slide-up (выдвижение снизу)

```css
@keyframes slideUp {
  0% {
    opacity: 0;
    transform: translateY(10px);
  }
  100% {
    opacity: 1;
    transform: translateY(0);
  }
}
```

### Вариант 3: Highlight-then-fade (выделение с последующей нормализацией)

```css
@keyframes highlightAndFade {
  0% {
    background-color: #fff9c4;
    color: #000;
  }
  100% {
    background-color: transparent;
    color: inherit;
  }
}

.injected-text {
  animation: highlightAndFade 800ms ease-out;
}
```

**Выбор варианта зависит от контекста:**
- **Fade-in**: мягко, ненавязчиво
- **Slide-up**: динамично, заметно
- **Highlight**: подчеркивает что добавилось новое
