## Детальное сравнение платформ

### Superwhisper (macOS/iOS Priority)

**Позиционирование**: Контроль, приватность, глубокая кастомизация для Power Users

| Характеристика | Значение |
|----------------|---------|
| **ОС** | macOS (приоритетно), iOS (базовый), Windows (ограниченно) |
| **Архитектура** | Локальная (On-device), опциональная облачная корректировка |
| **Модели STT** | Whisper (Nano/Base/Small/Medium/Large), Parakeet локально |
| **Модели LLM** | Локальные (Llama, Mistral) или облачные (Claude, GPT-4) |
| **Приватность** | 100% при использовании локальных моделей |
| **Инженерия промптов** | Максимальная: XML-тегирование, Custom Modes, Advanced Rules |
| **Интеграция** | Macrowhisper, Alfred, Raycast, AppleScript, Shortcuts |
| **Цена** | Lifetime (~$249) или подписка (~$8–10/мес) |
| **Уникально** | Полный контроль над семантикой, асинхронная маршрутизация |

**Целевая аудитория**: Разработчики, аналитики, пользователи с конфиденциальными данными

**Минусы**:
- Требует мощное железо (GPU для больших моделей)
- Кривая обучения для настройки
- Локальная обработка медленнее облачных моделей

---

### Wispr Flow (Универсальная платформа)

**Позиционирование**: Гладкий UX, кроссплатформенность, работает "из коробки"

| Характеристика | Значение |
|----------------|---------|
| **ОС** | macOS, Windows, iOS, Android (полная поддержка всех) |
| **Архитектура** | Облачная (Cloud-only), все данные обрабатываются на серверах |
| **Модели STT** | Proprietary cloud models (Wispr proprietary) |
| **Модели LLM** | Облачные с автоматической адаптацией стиля |
| **Приватность** | Standard encryption, но данные на серверах |
| **Инженерия промптов** | Автоматическая адаптация, ограниченная кастомизация |
| **Интеграция** | Command Mode, Shared Dictionaries, Cloud sync |
| **Цена** | Подписка (~$15/мес), бесплатный базовый уровень с квотой |
| **Уникально** | Лучший UX, Command Mode для редактирования, кроссплатформенность |

**Целевая аудитория**: Массовый пользователь, все кто хочет "работает из коробки"

**Минусы**:
- Требует интернет соединение
- Меньше контроля над промптингом
- Потенциальные проблемы с приватностью данных

---

### VoiceInk (Open-Source, локальный)

**Позиционирование**: 100% приватность, открытый исходный код, для энтузиастов

| Характеристика | Значение |
|----------------|---------|
| **ОС** | macOS, Windows, Linux (кроссплатформенно) |
| **Архитектура** | 100% локальная (On-device), никогда не отправляет данные |
| **Модели STT** | Whisper (любой размер, включая большие) |
| **Модели LLM** | Локальные: Llama, Mistral, GPT4All |
| **Приватность** | Максимальная (можно запустить offline полностью) |
| **Инженерия промптов** | Полный контроль, локальные XML-промпты |
| **Интеграция** | Shell-скрипты, локальные webhooks, AppImage |
| **Цена** | Бесплатно (open-source), опциональная $39 за compiled binary |
| **Уникально** | Open-source, можно модифицировать исходный код |

**Целевая аудитория**: Linux-разработчики, paranoid users, исследователи

**Минусы**:
- Требует сборка из исходного кода
- Малое сообщество
- Слабая поддержка и документация
- Требует мощное железо

---

### DictaFlow (Специалист: преодоление блокировок)

**Позиционирование**: Работает через VPN/RDP/Citrix, обход корпоративных ограничений

| Характеристика | Значение |
|----------------|---------|
| **ОС** | Windows (приоритетно), некоторая поддержка Linux |
| **Архитектура** | Гибридная: локальное VAD + облачная корректировка |
| **Модели STT** | Whisper + Parakeet |
| **Модели LLM** | Облачные, возможна локальная гибридизация |
| **Приватность** | Средняя (сжатие перед отправкой, опция локальной обработки) |
| **Инженерия промптов** | Средняя, активация дополнительных слоев грамматики |
| **Интеграция** | Низкоуровневая симуляция нажатий (Citrix Bypass) |
| **Цена** | Не указано явно |
| **Уникально** | "Citrix Bypass" — эмуляция нажатий через системные вызовы |

**Целевая аудитория**: Корпоративные пользователи, работающие через RDP/VPN

**Минусы**:
- Узкоспециализированный (только Windows)
- Менее популярен, хуже документирован
- Меньше интеграций

---

### Aqua Voice (Облачная, визуальный фокус)

**Позиционирование**: Лучший визуальный фидбек и UI, облачная корректировка

| Характеристика | Значение |
|----------------|---------|
| **ОС** | macOS, Windows (равноправная поддержка) |
| **Архитектура** | Локальная (Avalon модель) + облачная корректировка |
| **Модели STT** | Avalon (proprietary, optimized) |
| **Модели LLM** | Облачные (Claude, GPT-4o) |
| **Приватность** | Среднее (локальное распознавание, облачная обработка) |
| **Инженерия промптов** | Базовые кастомные инструкции |
| **Интеграция** | Focusable UI, плавающее окно, приложение-спутник |
| **Цена** | От $8/мес, план Enterprise для команд |
| **Уникально** | Лучшие анимации (Ghosting), отзывчивый UI |

**Целевая аудитория**: Пользователи, ценящие эстетику и плавность

**Минусы**:
- Требует интернет
- Меньше контроля над логикой
- Менее гибкая маршрутизация

## Выбор по сценарию

### Сценарий 1: Разработчик с конфиденциальным кодом

```
Требования:
✓ Локальная обработка (100% приватность)
✓ Контроль над промптингом (кастомные режимы)
✓ Интеграция с IDE и терминалом
✗ Не важна кроссплатформенность

Рекомендация: Superwhisper
```

### Сценарий 2: Корпоративный пользователь за RDP

```
Требования:
✓ Работа через удаленные соединения
✓ Не требуется глубокая кастомизация
✓ Windows-ориентированность
✗ Высокие требования к приватности

Рекомендация: DictaFlow
```

### Сценарий 3: Мобильный + Десктоп, все ОС

```
Требования:
✓ iOS + macOS + Android + Windows
✓ Простота использования (работает из коробки)
✓ Облачная синхронизация между устройствами
✗ Не критична абсолютная приватность

Рекомендация: Wispr Flow
```

### Сценарий 4: Linux разработчик, максимальный контроль

```
Требования:
✓ Может собрать из исходного кода
✓ Полный контроль над каждым модулем
✓ Бесплатное решение
✗ Не требуется коммерческая поддержка

Рекомендация: VoiceInk
```

### Сценарий 5: Дизайнер / создатель контента, красивый UI

```
Требования:
✓ Приятный, отзывчивый интерфейс
✓ Хороший визуальный фидбек
✓ Работает на обоих ОС
✗ Не требуется максимальная приватность

Рекомендация: Aqua Voice
```

## Тренды и будущее рынка

### Общее направление развития

1. **Гибридизация**: локальное VAD + облачная LLM
2. **Мультимодальность**: аудио + видео + текст
3. **Edge Computing**: модели на устройстве, синхронизация в облако
4. **Специализированные системы**: вертикали (юриспруденция, медицина, программирование)
5. **Оплата по использованию**: вместо подписок

### Консолидация рынка

Ожидается, что 2–3 крупных игрока поглотят smaller players:
- Microsoft (Windows integration)
- Google (Android + cloud infrastructure)
- Apple (macOS/iOS ecosystem lock-in)

### Нишевые возможности для стартапов

- Вертикальные решения (медицина, юриспруденция, программирование)
- Open-source инструментарий (замена облачным сервисам)
- Гибридные решения для ERP/CRM систем
- Интеграции с Notion, Linear, GitHub

## Выводы для разработчиков OpenVerb

**На рынке нет идеального решения:**

✓ Superwhisper = Контроль + Приватность, но Mac-ориентирован
✓ Wispr Flow = Кроссплатформа + UX, но облако-зависим
✗ Никто не сочетает: Полный контроль + Кроссплатформа + Облако-опциональная

**Возможность для OpenVerb:**
- Создать open-source альтернативу с лучшей модульностью
- Поддержать все платформы (Linux, Windows, macOS)
- Предоставить локальный контроль + облачную опциональность
- Документировать внутреннюю архитектуру (чего нет у конкурентов)
