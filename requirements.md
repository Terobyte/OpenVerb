# MVP 1: C++ Engine CLI

**Goal:** `openverb-engine --file audio.wav --context '{"app":"Slack"}'` → tailored text on stdout. Primary backend (Gemma 4 E2B audio-native) only. No IPC, no daemon, no Swift app.

**Spec:** `docs/superpowers/specs/2026-04-13-openverb-architecture-design.md`

**Depends on:** MVP 0 `DECISION.md` — quantization choice and confirmed llama.cpp audio path (mmproj or LiteRT-LM)

> **Assumption:** This plan is written for the **mmproj path**. If MVP 0 chose LiteRT-LM instead, replace `llama_context.h/.cpp` with `litert_context.h/.cpp` implementing the same `infer()` interface — the Backend abstraction isolates this change to one file. A separate addendum will cover the LiteRT-LM variant if needed.

## Audio Pipeline

- [ ] Write `engine/src/audio/reader.h`: struct `AudioData { vector<int16_t> samples; int sample_rate, channels, bits_per_sample; }`; declare `read_wav(path)` and `read_pcm(path)` returning AudioData; declare `peek_wav_duration_secs(path)` returning double — reads only the WAV header (44–80 bytes) to compute duration without loading sample data
- [ ] Write `engine/src/audio/reader.cpp`: parse WAV header (RIFF/WAVE/fmt/data chunks), validate PCM format code 1, support any sample rate and channel count; `peek_wav_duration_secs()` opens file, reads fmt + data chunk headers, returns `data_chunk_size / (sample_rate * channels * bits_per_sample / 8)` — does NOT allocate sample buffer; `read_pcm()` reads raw file as int16_t assuming 16kHz/16-bit/mono
- [ ] Write `engine/tests/test_reader.cpp`: test valid WAV read (correct sample count), 44.1kHz WAV (correct sample_rate), stereo WAV (channels=2), non-existent file throws, truncated WAV throws, WAV with extra chunks (LIST/INFO) before `data` → skipped gracefully, WAV with format code ≠ 1 (μ-law, ADPCM) → throws `"unsupported WAV format: only PCM (format 1) supported"` — uses fixtures from `engine/tests/fixtures/`
- [ ] Write `engine/src/audio/resampler.h`: declare `resample(const AudioData& input, target_rate=16000)` returning new `AudioData` and `to_mono(const AudioData& input)` returning new `AudioData` — both return copies, neither modifies input
- [ ] Write `engine/src/audio/resampler.cpp`: `to_mono()` averages L+R channels, returns new AudioData; `resample()`: for downsampling (e.g. 44.1→16kHz), apply **windowed-sinc low-pass filter** at target Nyquist (8kHz) before cubic interpolation — prevents aliasing artifacts that degrade Gemma WER; for upsampling (e.g. 8→16kHz), cubic interpolation alone is sufficient; returns copy unchanged if already target rate; no libsamplerate dep; applies mono first then resample
- [ ] Write `engine/tests/test_resampler.cpp`: test 16kHz mono passthrough, 44100→16000 (correct output count), stereo→mono (channels=1), 48kHz stereo → 16kHz mono (both conversions), 8kHz→16kHz (telephony upsampling), 1 sample input → no crash, 0-length input → returns empty
- [ ] Vendor WebRTC VAD source into `engine/third_party/webrtc_vad/` (not src/): files `webrtc_vad.h`, `webrtc_vad.c`, `vad_core.c`, `vad_filterbank.c`, `vad_gmm.c`, `vad_sp.c`, `signal_processing_library.h`, `spl_inl.h`; add as static library `webrtc_vad_lib` in CMakeLists; `src/audio/vad.h/.cpp` is the only wrapper — it `#include`s from `../../third_party/webrtc_vad/webrtc_vad.h`
- [ ] Write `engine/src/audio/vad.h`: class `Vad` with `is_speech(samples, num_samples)` returning bool, `filter(audio, sample_rate, silence_ms)` returning speech-only vector; minimum speech threshold: **< 7 frames (210ms)** — frame-aligned to 30ms WebRTC VAD frames; spec says "<200ms" but 200ms is not frame-aligned (6.67 frames), so we round up to 7 frames = 210ms as the canonical threshold; if total speech frames < 7, return empty
- [ ] Write `engine/src/audio/vad.cpp`: wrap WebRTC VAD C API, `filter()` walks 30ms frames tracking speech/silence state, keeps speech + trailing silence up to `silence_ms`
- [ ] Write `engine/tests/test_vad.cpp`: test silence buffer → is_speech false, sine wave → is_speech true, filter on silence → empty, filter on speech+silence+speech → preserves both segments, audio <30ms (single VAD frame) → handled without crash

## llama.cpp Wrapper

- [ ] Write `engine/src/config/interrupts.h`: `#pragma once`, `#include <atomic>`, `extern std::atomic<bool> g_interrupted;` — shared between `main.cpp` (sets it on SIGINT/SIGTERM) and `llama_context.cpp` (checks it during model load and generation loop); defined in `main.cpp` as `std::atomic<bool> g_interrupted{false};`
- [ ] Write `engine/src/inference/llama_context.h`: `#include <memory>`, `#include <string>`, `#include <vector>`, `#include <cstdint>`, `#include <functional>`; `using ProgressCallback = std::function<void(float)>`; class `LlamaContext` (PIMPL) with constructor `(model_path, mmproj_path, threads, ctx_size)`, `infer(text_prompt, audio_pcm, sample_rate, generation_suffix, progress_callback)` returning string, `has_audio_support()`, `model_name()`; non-copyable (delete copy ctor + assignment)
- [ ] Write `engine/src/inference/llama_context.cpp`: PIMPL wrapping llama.cpp C API — constructor calls model load + context init with `ctx_size` parameter (controls KV cache allocation — default 4096 for CLI, not llama.cpp's 131072 which wastes ~780 MB); exact function names depend on pinned llama.cpp tag — **placeholder names below, replace with actual API from MVP0**: likely `llama_model_load_from_file()` + `llama_new_context_with_model()` + mmproj via `clip_model_load()` or `llama_mmproj_init()`; MVP0 must record the confirmed API surface. **Chat template:** Gemma 4 uses a Jinja chat template (MVP0 confirmed: llama-mtmd-cli crashed with "this custom template is not supported, try using --jinja"). Constructor must enable Jinja template rendering via `llama_chat_apply_template()` with jinja=true, or manually format chat turns if the C API doesn't expose jinja mode — investigate in MVP0 API discovery. **Thinking mode:** Gemma 4 outputs `[Start thinking]...Thinking Process:...[End thinking]` before the actual answer. Two mitigations: (a) prepend `/no_think` to the user turn if Gemma 4 supports it (preferred — avoids wasting tokens), (b) post-process: strip everything between `[Start thinking]` and the end of thinking block from `infer()` output before returning. Implement both — (a) as default, (b) as safety net. **GPU memory:** before model load, query available Metal VRAM via `MTLDevice.recommendedMaxWorkingSetSize` (Objective-C bridge or sysctl); if available VRAM < model size + estimated KV cache (ctx_size * 2 * n_layers * d_model * sizeof(float16)), log warning to stderr `"warning: estimated VRAM usage (N MB) exceeds available (M MB), inference may be slow"`; do NOT fail — let Metal/llama.cpp handle spillover to system RAM. `infer()`: (1) tokenize `text_prompt`, (2) convert `audio_pcm` int16 → float32 normalized [-1.0, 1.0], (3) pass float audio + sample_rate to audio embedding API (exact function name from MVP0 validation — record it here when known), (4) tokenize `generation_suffix`, (5) concatenate [text_tokens + audio_embeddings + suffix_tokens], (6) run autoregressive generation loop with `progress_callback` every ~500ms — checks `g_interrupted` atomic (from `config/interrupts.h`) each iteration for graceful SIGINT abort, (7) decode output tokens to string, strip thinking block if present; destructor frees model+context+mmproj; throws `runtime_error` on load/OOM/inference failure. **If MVP0 chose LiteRT-LM:** replace this file with `litert_context.h/.cpp` implementing the same interface — Backend abstraction isolates the change.

## Engine + main.cpp

- [ ] Write `engine/src/engine.h/.cpp`: class `Engine(Config)` owns `unique_ptr<Backend>`; `process_file(file_path, context_json)` reads WAV/PCM (detect by extension **case-insensitively**: `.wav`/`.WAV`/`.Wav` → `read_wav()`, `.pcm`/`.raw` → `read_pcm()`, anything else → error exit 1); for WAV files: call `peek_wav_duration_secs(path)` **before** loading sample data — if duration > `MAX_RECORDING_SECS` (300s), error immediately without allocating memory (`"audio too long: Ns, max 300s"`); for PCM files: check duration after read (raw files have no header); after loading samples: compute RMS energy — if below silence threshold, skip inference and return empty InferenceResult (avoids wasting GPU on pure silence when VAD is off); **threshold must be calibrated** against `validation/audio/silence.wav` and quiet speech samples during integration testing — initial estimate RMS < 50 (int16), but this is unvalidated and may reject quiet speech; define as `SILENCE_RMS_THRESHOLD` in `defaults.h` for easy tuning; resamples to 16kHz/16-bit/mono, calls `backend_->process()`, returns `InferenceResult`; all error messages go to stderr prefixed `error: `
- [ ] Write `engine/src/main.cpp`: install signal handler for SIGINT/SIGTERM — sets atomic `g_interrupted` flag; checked in two places: (1) LlamaContext constructor checks after `llama_model_load_from_file` returns (aborts before context init if interrupted during multi-second model load), (2) generation loop checks each iteration (aborts cleanly, frees GPU buffers); parse args → resolve config (model auto-detected if --model omitted) → if `--version` print `openverb-engine OPENVERB_VERSION` and exit 0 → if no `--file` print `error: --file required` to stderr and exit 1 → create Engine → connect ProgressCallback: in `--verbose` mode, print `progress: N%\r` to stderr every callback (carriage return for in-place update); in non-verbose mode, no progress output → `process_file()` → **output format**: default: text result → raw string + `\n` to stdout, command result → `{"command":"<action>"}\n` to stdout (caller can distinguish by first char `{`; for unambiguous parsing use `--json`); **empty result** (text="" and no command): default mode → output nothing to stdout, exit 0 (caller distinguishes from error by exit code); `--json` mode → `{"text":"","command":null}\n`; with `--json` flag: always uniform JSON — `{"text":"...","command":null}\n` or `{"text":null,"command":"..."}\n`; both modes always end with `\n` for clean terminal output; verbose: inference time → stderr `inference: <N>ms` → catch exceptions → print `error: <message>` to stderr → exit 1 on error; on SIGINT → exit 130
